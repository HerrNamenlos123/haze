# Binary building blocks and traverse

stdlib pieces for writing binary file formats: ByteBuffer's binary writes, BinaryReader, RawMemory, crc32c, and traverse, the compile-time walk that calls a format's hooks.

Verified 2026-11-11 against bf4a25f5 plus the uncommitted .hznote work in .claude/worktrees/hznote.

- `ByteBuffer` (`stdlib/core/src/memory.hz`): `pushU16..pushU64`, `pushI8..pushI64`, `pushF32`, `pushF64` (exact bits), `setU32At` (patch a size), `push(RawMemory)`. Little-endian; `HZSTD_ASSERT_LITTLE_ENDIAN()` (hzstd_memory.h, a `_Static_assert`) stops a big-endian build.
- `BinaryReader` (`stdlib/core/src/binary.hz`): a value struct over memory it does not own (`BinaryReader(bytes)` keeps Bytes alive; `BinaryReader.overMemory(raw)` for caller memory). `readU8..readF64`, `readBytes`/`readStr` copy, `readView` slices (Bytes-backed only), `readInto(RawMemory)`, `sub(n)`. A read that does not fit returns 0, moves to the end and records `overrunAt()`: check `overran()` once per record. Mutate it through a field (`this.input.readU32()`), never through a copy (`let r = this.input` reads a copy).
- `crc32c` module (`stdlib/crc32c`): `hash(Bytes)`, `update(crc, Bytes)`, `hash(RawMemory)`; slicing-by-8 tables generated by a bitwise oracle.
- `traverse` (`stdlib/core/src/traverse.hz`; the header comment lists every hook): `describe` / `write` / `read<F, T>`. A format declares `skipAttribute: "x.skip" = "x.skip";` (read as `F["skipAttribute"].literalValue`); fields with that attribute are never walked and read back as default / none. Plain = a number, or a value struct whose numbers all have one size (no bool/str/Bytes, nothing skipped): `plainSize` checks it against C's sizeof and panics on a mismatch. Plain values and arrays of them go through `writePlain` / `readPlain` in one call when the format allows (`writesPlain` / `readsPlain`). `read` returns `Result<T, traverse.Failed>`; the format records what failed.
- `T.variants` is not in declaration order: identify variants by type, not position.
- Tests: `stdlib/core/tests/binary-tests.hz`, `traverse-tests.hz` (every hook in order, plain copy counts, field rules), `stdlib/crc32c/tests/crc32c-tests.hz`; runner `scripts/run-stdlib-test.sh <test> [modules]`.
- Traps hit writing them: an exported generic cannot call a non-exported helper from another module (export the helpers); passing a local to a `mut stackref` parameter needs `let stackref x = ...`; a recursive method needs `:: final` and an explicit return type; `type`, `from`, `plain` are reserved; a local named `none` shadows nothing and breaks every later `none`.
